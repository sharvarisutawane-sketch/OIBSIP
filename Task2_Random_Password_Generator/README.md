# Random Password Generator

## Objective
Generate strong random passwords based on user-selected criteria.

## Features
- Accepts password length (minimum 8).
- Supports uppercase and lowercase letters.
- Supports numbers and symbols.
- Allows selection of character types.
- Validates user input.
- Generates random passwords.

## How to Run
1. Install Python 3.
2. Open Command Prompt in this folder.
3. Run: py main.py
