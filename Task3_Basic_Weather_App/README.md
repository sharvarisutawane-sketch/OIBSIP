# Basic Weather App

## Objective
Fetch and display current weather for a city using OpenWeatherMap API.

## Features
- Accepts city name.
- Fetches current weather data.
- Displays temperature in Celsius and Fahrenheit.
- Displays humidity, weather condition and wind speed.
- Handles invalid city names and API errors.

## Requirements
- Python 3
- Requests library

## How to Run
1. Install dependencies:
   py -m pip install -r requirements.txt
2. Run the application:
   py main.py
3. Enter city name and API key when prompted.
